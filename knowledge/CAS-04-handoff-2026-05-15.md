## MA-side TODO (next session, MA scope)

### Endpoint: `GET /api/cas/render`

**Query params**:
- `slot` (required): `newsletter | infeed | banner` (banner reserved pentru CAS-05)
- `recipient` (newsletter only): SHA-256 hash of recipient email + salt
- `visitor` (infeed/banner): SHA-256 hash of visitor cookie/session
- `source` (required): consumer ID, e.g. `teinformez` (for attribution)

**Response (200 OK)**:
- Content-Type: `text/html; charset=utf-8`
- Body: HTML fragment ready to inject (no `<html>`/`<body>` wrappers)
- For newsletter: email-safe HTML (table layout, inline styles)
- For infeed: web-safe HTML (div + img + tracking pixel)
- Headers: `Cache-Control: private, max-age=300` (5-min cache acceptable, varies per recipient hash)

**Response (204 No Content)**: when no ad inventory matches recipient profile (consumer should render nothing — empty slot, NOT error)

**Response (4xx)**:
- `400` invalid params (missing slot, malformed hash)
- `401` invalid X-API-Key
- `429` rate-limited (return Retry-After)

**Authentication**: `X-API-Key` header (server-side, per consumer); for client-side InFeed use a separate `NEXT_PUBLIC_MA_CAS_KEY` (read-only, rate-limited per origin).

**Tracking pixel**: each rendered ad includes `<img src="${MA_URL}/api/cas/track?event=impression&adid=<>&recipient_hash=<>&source=teinformez" width=1 height=1>` for impression counting.

**Click tracking**: ad CTA URLs go through `${MA_URL}/api/cas/click?adid=<>&recipient_hash=<>&source=teinformez&dest=<encoded-url>` redirect.

### Storage model (MA side)

Tables needed:
- `cas_campaigns`: `id, name, status (active/paused), slot, targeting_json, creative_html, start_at, end_at, owner_id`
- `cas_impressions`: `id, campaign_id, source, recipient_hash, visitor_hash, slot, timestamp`
- `cas_clicks`: `id, campaign_id, source, recipient_hash, visitor_hash, dest_url, timestamp`
- Indexes pe `(campaign_id, source, timestamp)` + `(recipient_hash, slot)`

### Admin UI (MA side)

- `/admin/cas` list page — campaigns table cu status + slot + impressions/clicks 7d
- `/admin/cas/new` — campaign creation form (slot select + HTML editor + targeting + dates)
- `/admin/cas/[id]/metrics` — per-campaign metrics (impressions, CTR, by-source breakdown)
